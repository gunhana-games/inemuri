# うとうと学園

授業中、先生にバレずに居眠りしろ。
長押しで目を閉じると眠気が下がる。でも、先生に見られたらアウト。当てられたら、すぐに答えろ。時間割は、終わらない。
ブラウザで遊べる無料ゲームです。

▶ **遊ぶ：https://gunhana-games.github.io/inemuri/**

## ファイル

- `index.html` … ゲーム本体
- `scenes.js` … 場面のデータ（教科・問題・先生の話・時間帯・イベントなど）
- `img/people/` … 社会の人物写真の問題で使う画像（パブリックドメイン。出どころは `CREDITS.txt`）
- `ogp.png` / `icon.png` … SNSのカード画像とアイコン（`tools/make_ogp.py` で作成）
